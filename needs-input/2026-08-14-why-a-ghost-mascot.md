## สิ่งที่หาเจอเองแล้ว

เช็คซอร์สโค้ดของ luiquest repo (github.com/ARCHEMETIS/luiquest) แล้ว เจอเยอะมาก:

- ผีตัวนี้อยู่ใน `src/components/GhostMascot.jsx` เป็น pixel art วาดด้วย CSS grid 8×9 ช่อง
  สีที่ใช้จริงคือม่วงอ่อน `#A78BFA` กับม่วงเข้ม (violet) `#8B5CF6` เป็นสีตัวหลัก
  มีท่าทางหลายแบบ: idle, celebrate, sad (ร้องไห้ มีแอนิเมชันหยดน้ำตา), sixseven, fireworks, rankup, groove
- `src/components/NavMascot.jsx` ทำให้ผีเดินไปมาบนแถบเมนูล่าง โผล่ข้อความพูดเป็นบับเบิลเป็นระยะ
  แตะแล้วพาไปหน้าโค้ช ในโค้ดมีคอมเมนต์ภาษาไทยของพี่เองว่า:
  - "เจ้าของขอ: หน้าแรก 'ยังดูเรียบ ๆ ยังไม่มีลูกเล่น'" — นี่คือเหตุผลที่มา
  - "คนชอบแตะอวตาร/ตัวการ์ตูนก่อนเป็นอันดับแรก" — เหตุผลว่าทำไมต้องแตะได้
  - แตะรัวๆ ผีจะหันหลังให้ (งอน, mood แบบ sad) ก่อนจะให้อภัย
- `src/lib/mascotChatter.js` เลือกข้อความพูดตามสถานะจริงของผู้ใช้ (streak ใกล้ขาด, ทำ milestone ได้, เลื่อนแรงค์)
  คอมเมนต์ในโค้ดอ้างถึง Duolingo/Finch เป็นต้นแบบ และบอกว่าข้อความให้กำลังใจแบบทั่วไปจะถูกมองข้ามภายในไม่กี่วัน
- ผีโผล่ทั่วแอป: หน้าโค้ช (เป็นอวตารของ AI coach), หน้าเควสประจำวัน, หน้าการ์ด streak, ตอนชวนติดตั้งแอปลงหน้าจอโฮม,
  หน้า onboarding, หน้า premium, และอื่นๆ
- เจอ 2 commit ที่เกี่ยวกับผีโดยตรง (5 ส.ค. 2026): "Let the ghost invite people to keep the app on their home screen"
  และ "Stop the ghost from sitting on top of the install text" — แต่ทั้งสองเป็นเรื่องแก้บั๊ก/ฟีเจอร์ย่อย
  ไม่ได้อธิบายที่มาว่าทำไมเลือกเป็นผีตั้งแต่แรก
- README ของ repo ไม่พูดถึงมาสคอต/ผีเลยแม้แต่คำเดียว
- ไม่มีที่ไหนในโค้ดหรือ commit อธิบายว่า **ทำไมถึงเลือก "ผี"** (ไม่ใช่สัตว์ ไม่ใช่การ์ตูนแบบอื่น)
  และ **ทำไมต้องสีม่วง** — เรื่องนี้ตรงกับที่ author-notes.md ระบุไว้แล้วว่ายังไม่ได้เล่า

## คำถาม

1. ตอนที่บอกว่า "หน้าแรกยังดูเรียบ ยังไม่มีลูกเล่น" แล้วเลือกใส่มาสคอต ทำไมถึงเลือกเป็น "ผี" — คิดถึงตัวอื่นก่อนไหม (เช่น สัตว์, หุ่นยนต์, ตัวการ์ตูนทั่วไป) แล้วทำไมผีชนะ
2. สีม่วงมาจากไหน — เลือกเพราะอะไร (เช่น สีที่ชอบ, ธีมสีของแอป, หรือเหตุผลอื่น)
3. ท่าทางแบบ "งอน" ตอนแตะรัวๆ (หันหลังให้ ทำหน้า sad ก่อนให้อภัย) พี่คิดโมเมนต์นี้เองไหม มีที่มาจากไหน หรือได้ไอเดียจากที่ไหน
4. ตอนทดสอบเองเจอผีทำท่าไหนแล้วชอบที่สุด หรือมีโมเมนต์ไหนที่รู้สึกว่า "ผีตัวนี้ใช้ได้จริง" ทำให้มั่นใจว่าเลือกถูก

ตอบสั้นๆ พอครับ ไม่ต้องเรียบเรียง — เอาไปเขียนเป็นโพสต์เอง
