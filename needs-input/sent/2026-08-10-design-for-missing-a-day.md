# คำถามสำหรับหัวข้อ #4: ออกแบบให้คน "พลาดได้"

จากแผน (`content-plan.md`): เบื้องหลังข้อความตอน streak ขาด ("คนเก่งไม่ใช่คนไม่เคยพลาด แต่คือคนที่กลับมาลุยต่อ")
ทำไมถึงไม่ใช้ความรู้สึกผิดแบบ Duolingo

## สิ่งที่หาเจอเองแล้ว

- ยืนยันแล้วจาก content-plan.md (เขียนไว้ตอนโพสต์ how-to-use): ถ้า streak ขาด แอปไม่ด่า
  ขึ้นข้อความให้กำลังใจ ("คนเก่งไม่ใช่คนไม่เคยพลาด แต่คือคนที่กลับมาลุยต่อ") แล้วเริ่มนับใหม่
- เช็ค commit history ของ luiquest repo (github.com/ARCHEMETIS/luiquest) แล้ว —
  ไม่มี commit ไหนพูดถึง streak, การพลาด, หรือข้อความให้กำลังใจโดยตรง
  เจอแต่เรื่องระบบ XP/level ทั่วไป (เช่น "Turn progress into one game ladder: XP -> level -> rank")
  ไม่มีเหตุผลเบื้องหลังการตัดสินใจเรื่องนี้ในโค้ดหรือ commit message เลย
- เพราะงั้นเรื่อง "ทำไมไม่ใช้ระบบทวงแบบ Duolingo" เป็นเรื่องในหัวพี่ล้วนๆ ที่ยังไม่มีในไฟล์ author-notes.md
  (ไฟล์ระบุไว้แล้วว่านี่คือหนึ่งในเรื่องที่ยังไม่ได้เล่า)

## คำถาม

1. ตอนเลือกไม่ใช้ระบบทวงแบบ Duolingo (เช่น notification เร่ง หรือ streak freeze ที่ต้องจ่าย) พี่คิดอะไรอยู่ตอนนั้น — มีประสบการณ์ตรงกับ Duolingo หรือแอปอื่นที่ทำให้อยากทำต่างออกไปไหม
2. ประโยค "คนเก่งไม่ใช่คนไม่เคยพลาด แต่คือคนที่กลับมาลุยต่อ" พี่คิดเองไหม หรือมีที่มา/แรงบันดาลใจจากไหน
3. ตอนทดสอบแอปเอง เคย streak ขาดจริงไหม แล้วตอนเห็นข้อความนี้ขึ้นมา รู้สึกยังไง
4. มีจังหวะไหนที่พี่ลังเลว่าจะใส่ระบบทวง/บทลงโทษแบบแอปอื่นบ้างไหม แล้วสุดท้ายตัดสินใจไม่ใส่เพราะอะไร

ตอบสั้นๆ พอครับ ไม่ต้องเรียบเรียง — เอาไปเขียนเป็นโพสต์เอง
