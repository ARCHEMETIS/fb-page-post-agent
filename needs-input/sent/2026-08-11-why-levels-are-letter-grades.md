## ทำไมข้ามหัวข้อ #4 มาก่อน

หัวข้อ #4 (ออกแบบให้คน "พลาดได้") ถามไปแล้วเมื่อ 10 ส.ค. (`needs-input/sent/2026-08-10-design-for-missing-a-day.md`)
ยังไม่มีคำตอบใน author-notes.md เลยไม่ถามซ้ำ — ขยับมาหัวข้อ #5 แทนเพื่อให้มีคำถามกองไว้ให้ตอบพร้อมกันได้

## สิ่งที่หาเจอเองแล้ว

- เช็ค commit history ของ luiquest repo (github.com/ARCHEMETIS/luiquest) แล้ว โดยเฉพาะ commit
  "Turn progress into one game ladder: XP -> level -> rank" (58ce03b, 23 ก.ค. 2026) — commit นี้แก้เรื่อง
  progress bar ที่เคยเด้งกลับไป 0% ทันทีหลังขึ้นแรงค์ใหม่ เปลี่ยนมาให้ XP เติมแถบเลเวลแล้วถึงเลื่อนแรงค์
  แต่ **ไม่มีตรงไหนพูดถึงว่าทำไมถึงเลือกใช้ตัวอักษรเกรด (F/D/C/B/A) แทนตัวเลข level 1,2,3...** เกรดมีอยู่แล้วตั้งแต่ก่อน commit นี้
- ยืนยันจากโพสต์ how-to-use ที่ลงไปแล้ว: เลเวลในแอปคือ F → D → C → B → A มีแถบ XP กำกับ (เช่น 10/25 XP ไป Lv.2)
- เจอ curve ที่ใช้จริงจาก commit เดียวกัน: ต้องใช้ 25 XP ขึ้น level 2 แล้วเพิ่มทีละ 5 ต่อเลเวล
  ที่อัตรา XP เฉลี่ยวันละ ~20 จะได้ D ~วันที่ 1, C ~วันที่ 5, B ~วันที่ 9, A ~วันที่ 17 แล้วมี S/SS/SSS ต่อยอด
  ให้คนเล่นนานๆ ยังมีอะไรให้ไต่ต่อ (~28/45/67 วัน) — เอาไปใช้ในโพสต์ได้เลยโดยไม่ต้องถามเพิ่ม
- ไม่เจอในโค้ดหรือ commit message เลยว่าทำไมเลือกตัวอักษรเกรดแทนตัวเลข — เรื่องนี้เป็นการตัดสินใจในหัวพี่ล้วนๆ
  ที่ author-notes.md ระบุไว้แล้วว่ายังไม่ได้เล่า

## คำถาม

1. ตอนออกแบบระบบเลเวล ทำไมถึงเลือกใช้เกรด F D C B A แทนตัวเลข level 1 2 3 — คิดถึงอะไรตอนนั้น
2. F ปกติคือเกรดตกในระบบการศึกษา ตอนตัดสินใจใช้ F เป็นเลเวลเริ่มต้นที่ทุกคนต้องเจอ กังวลไหมว่าจะรู้สึกแย่ตั้งแต่วันแรก หรือคิดว่านี่คือจุดที่อยากให้รู้สึกแบบนั้นพอดี
3. มีแรงบันดาลใจจากที่ไหนไหม เช่น เกรดในโรงเรียน เกม หรือระบบอื่นที่เคยเจอแล้วอยากทำตาม/อยากทำต่าง
4. เคยลองทำเป็นตัวเลขมาก่อนไหม แล้วมีจุดไหนที่เปลี่ยนใจมาใช้ตัวอักษรแทน

ตอบสั้นๆ พอครับ ไม่ต้องเรียบเรียง — เอาไปเขียนเป็นโพสต์เอง
